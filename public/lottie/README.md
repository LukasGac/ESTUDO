# Animações Lottie dos Dinossauros

Coloque os 4 arquivos JSON aqui com os nomes exatos abaixo:

| Arquivo         | Dinossauro     | Link para download                                    |
|-----------------|----------------|-------------------------------------------------------|
| trex.json       | T-Rex          | https://lottiefiles.com/free-animations/t-rex         |
| triceratops.json| Triceratops    | https://lottiefiles.com/free-animations/triceratops   |
| pterodactyl.json| Pterodáctilo   | https://lottiefiles.com/free-animations/pterodactyl   |
| brachiosaurus.json| Braquiossauro| https://lottiefiles.com/free-animations/dinosaur      |

## Como baixar

1. Acesse o link correspondente
2. Escolha qualquer animação gratuita que gostar
3. Clique em "Download" → "Lottie JSON"
4. Renomeie o arquivo conforme a tabela acima
5. Coloque nesta pasta (public/lottie/)

O app detecta automaticamente quando os arquivos estão presentes
e troca o fallback SVG pela animação Lottie.
